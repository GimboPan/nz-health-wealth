# 内容与来源规范

## 三层内容分别记录

1. **节目观点**：发言人、身份、节目、日期、单集 ID、时间戳、观点摘要、商业关系、核验方式。嘉宾在节目里说过，不表示事实已被独立证实。
2. **公共资料**：主管部门或第一手材料的标题、链接、查核日期、适用人群与地区。公共教育机构的建议要按建议标注，不写成法律硬要求。
3. **编辑整理**：将材料转成动作的步骤、问题清单与英文问法；明确由本工程自行撰写，不伪装成原话。

## 状态边界

- `本次核对`：在标明日期，通过官方/公共来源网页检索核对了条目中的公共资料部分。并非逐句验证整条，也不是专业审核。
- `节目经验`：保留为经验性参考，附查证入口；未完成作为统一规则的核实，不写核对日期冒充当前事实。
- 所有首版条目均是编辑初稿。未听原音的材料不能写“听音确认”。

## 摘录与版权

保留本地参考库，不把完整字幕或音频提交到 GitHub。自行改写摘要，尽量使用来源定位代替长引用。引用第三方资料须遵守适用版权和许可；本项目的内容许可不扩张到第三方材料。

## 高风险的简化要避免

- “注册 GP 后所有看病都免费”。
- “药师自动知道你吃的全部药”。
- “所有专科都必须由 GP 转介”。
- “ACC 只承保突然受伤，渐进性伤害一律不赔”。
- “免费心理服务一定当天见到”。
- “KiwiSaver 的政府补贴每年永远是同一个金额”。
- “投资者登记或公司牌照意味着本金安全”。
- “嘉宾的基金、保险或诊疗服务是独立推荐”。

## 每次修改

定义需要核对的具体句子 → 阅读原始上下文 → 查当前第一手资料 → 写清限制 → 更新日期和状态 → 构建检查 → 在手机与桌面读一遍。发现规则冲突或可能造成延误就医/财务损失时，先撤下或收窄条目，再继续核实。

## 时间戳与来源用途（v0.2）

每条节目引用必须给出真实说话人段落的起止秒数、显示时段、说话人标签及段落哈希。时段可较中文摘要更长，不能假装逐词对齐。`节目依据` 支持条目的核心经验；`节目背景` 只说明问题来源，现行政策/费用另看公共资料。

找不到对应节目段落时保留 `official-supplement` 与 `sourceGap`，不补造时戳。节目中的学位头衔不能自动当医学资质；个案、广告、服务提供者的偏好不能写成普遍结论。

查核表记录网页检索层面的日期与范围；没有取得完整官方正文时，不写“全文核验”。来源图和候选计数不代表全部语义审阅。
