# 看GP前后 问诊准备与结果追踪模板

资料核对：2026年10月25日 · 问题与模板由编辑撰写

看诊前把最想解决的问题讲清楚，离开前把后续责任问明白。这张模板可以复制到自己的笔记，或打印带去诊所；填写内容留在自己手中，无需上传到本项目。

## 预约前准备一张简短清单

| 要写下的事 | 你的记录 |
| --- | --- |
| 这次最希望解决的一到两个问题 | ______ |
| 症状何时开始、怎样变化、怎样影响生活 | ______ |
| 正在用的处方药、非处方药和补充剂，以及过敏信息 | ______ |
| 已做的检查、相关结果和看过的服务 | ______ |
| 最担心的事，以及希望问的问题 | ______ |
| 需要的口译、陪同或更长预约 | ______ |

预约时说明问题数量和沟通需要，让诊所确认时长与费用。不要为了“准备充分”自行停药，或默认先去抽血；是否需要检查、何时做，由医疗团队评估。急迫情况也不必为等熟悉的GP而延误处理。

## 诊室里可以问的五个问题

1. 现在最可能的解释是什么，还有哪些不确定？
2. 这个检查或治疗要解决什么问题，结果会怎样改变下一步？
3. 有哪些可选做法，包括暂时观察？各自有什么收益、风险和费用？
4. 哪些变化需要提前回来或另寻紧急帮助？
5. 我能否拿一份书面计划，确认自己理解正确？

HDC的信息权利包括了解情况、可选方案及相关风险、收益和费用，获得检查结果，并可以要求书面信息摘要。以下问题是本项目把这些权利整理成的沟通工具，不是医生必须使用的固定问诊脚本。[HDC：信息与沟通权利](https://www.hdc.org.nz/your-rights/the-code-and-your-rights/your-rights-when-using-a-health-or-disability-service-what-to-do-if-you-have-any-concerns/)

## 做检查或转介时 当场填好追踪表

| 项目 | 约定内容 |
| --- | --- |
| 检查／转介是什么，何时、在哪里做／发送 | ______ |
| 哪个团队接收结果或转介 | ______ |
| 谁负责解释结果、决定下一步 | ______ |
| 预计何时、通过什么方式联系我 | ______ |
| 到约定时间没有消息，应联系谁、怎样联系 | ______ |
| 等待期间怎样照护，哪些变化需提前复评 | ______ |
| 复诊时间和可能费用 | ______ |

不要把“没消息”理解成“结果正常”。患者门户可能显示部分结果，但看到数值不等于已经完成解释和随访。GP也不一定能看到另一机构的全部资料；问清能否共享，必要时索取副本带去。

转介之后，确认是否已发送、接收方是谁，以及谁通知后续安排。如果病情改变，联系负责的医疗团队重新评估；这与重复催问来争取插队不同。[Health NZ：Planned care](https://www.healthnz.govt.nz/hospitals-services/services-support/planned-care)

## 两段可直接使用的英文

诊室里：

> What is this test intended to find out, and how would the result change the plan? Could I have a written summary of the next steps?

追踪结果时：

> I had [test] on [date] at [service]. We expected an update by [agreed date]. Could you confirm who is responsible for reviewing the result, whether it has arrived, and what I should do next?

这里的日期应填实际约定，不自行套用一个统一等待期限。不要在公开评论、GitHub issue或本项目反馈里粘贴个人病历。

## 仍不明白时 怎样继续问

先把不理解的判断、结果或选项列出来，请现有团队解释；需要时询问如何取得第二意见、带哪些资料、是否转介，以及费用由谁承担。获得另一意见不等于必定公费，也不要因此延迟紧急处理。[HDC：获取另一意见的相关权利](https://www.hdc.org.nz/your-rights/the-code-and-your-rights/your-rights-when-using-a-health-or-disability-service-what-to-do-if-you-have-any-concerns/)

[一位GP的节目回顾](https://gimbo.co.nz/fitness/one-gp)保留在Fitness；其中的沟通经验可以启发问题，但个人观点和口头百分比不构成所有GP的做法或疗效保证。本模板依据当前公共资料独立编写，没有新增节目时间戳。
